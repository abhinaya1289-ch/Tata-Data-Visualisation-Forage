## About This Project

This repository contains my work for the **Tata Group Data Visualisation** virtual internship simulation on [Forage](https://www.theforage.com/). The simulation focused on creating meaningful business dashboards and visual insights from retail transaction data.

---

## Dashboard Overview

Built using **Power BI Desktop**, the dashboard (`FORAGE_INTERNSHIP.pbix`) includes:

| Visual | Description |
|--------|-------------|
| Bar Chart | Sum of Revenue by CustomerID — identifies top revenue-generating customers |
| Map Visual | Sum of Quantity by Country — global sales distribution |
| Horizontal Bar | Revenue and Quantity by Country — top 10 countries comparison |
| Line Chart | Revenue by Year and Month — time-series trend analysis (2011) |

### Key Insights
- The top customer (CustomerID blank/bulk) contributed **₹1.76M** in revenue — likely B2B bulk orders
- **Netherlands, EIRE, and Germany** were the top 3 countries by revenue
- Revenue peaked in **November 2011** at ~₹1.5M, with a sharp spike in September (₹10,58,590)
- European countries dominated sales volume, with minimal presence in Asia-Pacific
